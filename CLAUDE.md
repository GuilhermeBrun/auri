## Antes de marcar o PR como pronto

1. Rodar as verificações de "Verificar antes de dizer que terminou" e mostrar a saída.
2. `/code-review` no diff da branch. Se o PR mexe em algum caminho das Code Review Rules (dados de
   paciente, cópia, migração, recepção, conexão, assinatura, atualização, workflows), também
   `/security-review`.
3. Corrigir o que for real; o que ficar de fora vai explicado na descrição do PR.
